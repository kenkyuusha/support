## for bots and agents

[wallets.json](wallets.json) · [raw JSON](https://raw.githubusercontent.com/kenkyuusha/support/main/wallets.json)

The JSON contains one entry per token and network, with explicit `token`, `network`, and `address` fields. All entries are for mainnet. `address` is the receiving wallet address. `token_contract` and `token_mint` identify the asset; they are not receiving addresses. For Solana SPL tokens, `address` is the owner wallet address. `chain_id` is the numeric EVM chain ID where applicable.

Token references: [Tether](https://tether.to/en/supported-protocols/), [Circle](https://developers.circle.com/stablecoins/usdc-contract-addresses), [BNB Chain](https://github.com/bnb-chain/mpp-sdk#tokens).
